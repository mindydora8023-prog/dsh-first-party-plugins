# 更新记录

## 0.6.0

- 设置页主列表提到清理面板之前。清理设置默认折叠，顶部保留「即将清理 N / M」计数。
- 排序：最新 / 最早 / 按标题（Cline 历史列表的排序，不做费用排序）。可按工作目录末级分组（dsh-archive-manager 按项目分组）。
- 每行用相对时间（刚刚 / N 分钟前 / 昨天 / N 天前），可复制会话 ID。即将被自动清理的会话带「即将清理」标记，并可「只看即将清理」（Notion 回收站的保留期提示）。
- 删除确认框列标题，不再只列会话 ID；超过 8 条收成「+N」。批量操作显示「进度 i / N」，失败行用标题而不是辣 ID。筛选之外仍选中的数量会单独显示，全选不会清掉它们。
- 新增只读 `previewCleanup`：与真实清理走同一次扫描，`dryRun` 不删除。保存保留天数或完成一次删除后重新计数。
- 预检里只要有不能连带删除的项，批量确认和单条确认一样禁用，不会先提交再把失败留到结果里。删除类按钮的红色统一走 `--dsw-alias-status-error`。

## 0.5.1

- 修复：**自动清理**删除已归档会话后，被删会话仍留在会话列表里、必须重启才消失。根因是后台清理
  只把 id 从归档集合里删掉，而客户端会话列表是按 `api-session/*` 事件增量维护、后台删除不会重新
  拉取；归档过滤一取消，旧行就露了出来。现在删除事务在元数据提交后，为每个被删会话补发宿主的
  `api-session/removed` 冷会话移除帧（与 live 会话的 `session/disposed` 同一条通道），侧栏、归档
  过滤与列表存储在**没有打开设置页时也能即时一致**。设置页「立即清理」原本就会 `sessions.refresh()`，
  所以受影响的是后台定时清理这条路径。
- 回归测试：单删、级联删除分别断言为每个被删 id 发 `api-session/removed`；元数据写失败时断言**不发**
  任何移除事件（删除未提交不得误导客户端）。

## 0.5.0

- 新增**自动清理**：后台定时（启动后约 90 秒首扫，之后每小时）删除「最后活动」超过设定天数
  （默认 5 天）的已归档会话，隐藏子 Agent 一并级联清理。设置页新增「自动清理」面板，可开关、
  修改保留天数、查看「上次清理」摘要，并可「立即清理」。
- 「最后活动」取**会话日志文件 mtime 与 header.createdAt 的较大值**——归档时间宿主没有记录，
  用最后活动既符合「旧」的直觉，又能保留最近还在用的会话。无任何时间戳的记录跳过而不猜。
- 复用同一个 `deleteArchived` 事务删除（租约、隔离、元数据回滚完全一致）；live、仍活跃、
  被级联规则拒绝的会话一律跳过；单个失败不中断整轮。配置与上次结果写在
  `%LOCALAPPDATA%\\dsh-plugins\\archived-sessions\\cleanup.json`（不进源码树）。
- 新增 `lib/cleanup.js`、`lib/state-dir.js`；新增 `test/cleanup.test.mjs`（年龄判定、跳过规则、
  错误隔离、dry-run、配置持久化、清理路由）。

## 0.4.0

- 新增**孤儿会话**清理：父会话日志已彻底不存在的子 Agent，既不在任何列表里、也没有归档记录
  提到它们，此前**没有任何入口可以删除**。设置页新增「孤儿子 Agent」面板，打开即自动扫描，
  显示每个孤儿及其缺失的父会话 ID，可一键清理。
- 孤儿判定与归档级联**互不重叠**：父会话仍在归档列表里（只是日志丢了）的子会话不会被重复
  上报，它们跟随那条归档记录一起清理，避免同一份日志被列两次。
- 删除/清理后同时调用 `ctx.sessions.refresh()` 与工作区 store，列表立即反映结果，不用手动刷新。
- 重构：归档删除与孤儿清理共用同一个 `runRemoval` 事务（解析路径 → 加锁 → 隔离 → 清理元数据
  → 失败回滚 → 删隔离目录），两条路径的安全校验完全一致。
- 测试增至 32 项：新增孤儿识别、孤儿与归档级联不重叠、workspace/已归档/live 三类阻塞、
  页面陈旧时拒绝、清理计数、空列表 no-op、孤儿路由参数校验。

## 0.3.0

- 修复「仍在子会话或分支引用此会话（N 个）… 不能仅重试删除」的死锁：当引用方全部是
  **隐藏子 Agent**（`origin: subagent`、不在归档列表里）时，删除确认框会列出它们并允许
  「一并清理」，按 parentSession 闭包级联删除，含多级子代理。
- 修复幽灵条目：磁盘上已无日志、只剩 `workspace.json` 归档记录的会话不再是 404 死路，
  删除时只清理元数据并在结果里报告 `ghosts`。
- 新增只读「删除预检」接口（`action: 'inspect'`）：设置页在确认前先展示将连带删除的子 Agent、
  残留记录，以及**不能**连带删除的阻塞项。
- 级联仍然严格拒绝：独立分支（`origin` 非 subagent）、挂在工作区里的会话、自身也在归档列表中
  的子会话、以及仍被宿主占用的会话——这些必须先单独处理，不会静默跳过。
- 批量删除按「预检可用项」执行，逐项汇总成功/失败/清理的子 Agent 数量。
- 测试增至 25 项：新增级联删除、幽灵条目、无 `cascade` 时磁盘零改动、预检路由校验。
