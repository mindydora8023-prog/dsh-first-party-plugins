# 会话费用估算

在 DeepSeek Harness 输入区显示当前会话费用，并为适用的 DeepSeek 模型显示峰谷时段。版本 0.5.1，MIT 许可证。

## 计算方式

- 按每次请求实际使用的模型和 token 用量计价，合计为当前会话费用。
- DeepSeek 模型优先使用内置价格表与峰谷规则。
- 其他模型通过在线目录匹配价格，再换算为人民币。
- 历史轨迹尚未完整加载时，差额用当前模型费率补估，明细显示这部分 token 数。
- 部分用量缺价时显示「已计价小计」，明细列出缺价 token 数。全部缺价时显示「未定价」。已知零费率仍按零元显示。[缺价呈现参考](https://github.com/ccusage/ccusage/blob/main/docs/guide/json-output.md#unpriced-models)
- 有缓存读取且缓存价低于输入价时，胶囊显示这笔读取按输入价计费会多付的金额。
- 上下文超过窗口一半时，胶囊显示占用百分比：一半到 80% 为警告色，80% 以上为危险色。不到一半或路由没有报告窗口时，数字留在悬停里。宿主自己的上下文环仍在同一行。
- 价格齐全、至少两次请求且间隔超过一分钟时，悬停显示花费节奏。不足一小时显示会话累计，超过一小时折成每小时。
- 点击胶囊后，每个模型单独成块，列出花费以及输入、输出、缓存读取。面板宽度随窗口调整。悬停仍可查看模型、单价与峰谷切换倒计时。最后一小时的倒计时直接显示在胶囊上。
- 还没有用量时不显示零金额。没有高峰价的模型此时不占输入框那一行；有高峰价的模型只显示时段。

明细可复制为 CSV 或 JSON，也可查看最近请求的逐条费用。日账本按请求开始时的浏览器本地日期归档，以会话和请求标识去重。面板的「今日累计」覆盖本机已看到、有开始时间且可计价的请求。显示金额为估算，实际结算以模型服务商账单为准。内置价格和节假日规则需要随服务商调整维护。

## 花费报表

点击费用胶囊，在「AI 花费报表」中选区间，点击 **HTML**、**JSON** 或 **CSV** 下载。默认导出当前自然月，可改选其他月份、近 30 天（含当天）、全部保留记录或自定义起止日期（含两端）。

- HTML 可直接双击打开，自带每日花费柱状图和模型对比表，随浏览器的亮色或暗色偏好调整。JSON 包含总计、模型和每日数据，CSV 可导入电子表格。
- 报表以人民币计。缓存节省率为可拆解的缓存节省金额 ÷（相应已计价花费 + 缓存节省金额）。缓存命中率为缓存读取 token ÷ 全部输入 token，输入包含缓存读写。单次均价以已计价请求为分母，花费占比以区间总花费为分母。缺价请求仍计入请求数和 token，金额待价格可用后补齐。
- 账本存放在当前浏览器，最多保留 60 个有记录的日期，每日最多 200 个会话，体积接近上限时优先保留最近日期。已归档的日期在更换时区后保持原样。旧版只存金额的记录仍计入总花费与趋势，模型和缓存明细只能在有对应请求记录时补齐。

面板在浏览器本地生成报表。其他本机工具也可向 `POST /session-meter/report` 提交 `application/json`。以下请求导出 2026 年 11 月的中文 HTML。

```json
{
  "format": "html",
  "language": "zh",
  "options": { "period": "month", "month": "2026-11" },
  "ledger": { "version": 3, "days": {} }
}
```

接口返回附件，格式可选 `html`、`json`、`csv`。调用方提供账本，接口处理后即丢弃。近 30 天使用 `{"period":"last30","today":"2026-11-28"}`，全部记录使用 `{"period":"all"}`，自定义使用 `{"period":"custom","from":"2026-11-01","to":"2026-11-15"}`。日期按账本中的本地日历字符串匹配。

## 外部数据

宿主端运行时可请求以下服务，并缓存结果：

- 价格目录：<https://models.dev/api.json>。版本 0.3.52 起，只有请求里出现非 DeepSeek 模型才下载；只用 DeepSeek 时不再在启动时拉取。版本 0.3.53 起，目录匹配兼容分发变体名（剥除 preview/latest/free/contributor 等发行尾缀）、版本分隔符写法（`1-0` 与 `1.0`）与 canonical 官方 id 索引，确切候选仍未命中时才启用受控兜底（剥尾后归一相等、家族首段相同、末段非身份词、目录中唯一）。
- 美元兑人民币汇率：<https://open.er-api.com/v6/latest/USD>
- DeepSeek 内置价格表参考：<https://api-docs.deepseek.com/zh-cn/quick_start/pricing>
- 若宿主进程提供 `SESSION_METER_DEEPSEEK_KEY` 或 `DEEPSEEK_API_KEY`，在本机打开明细时可从 DeepSeek 官方接口读取账户余额。宿主缓存成功结果 60 秒。

DeepSeek 条目不通过在线目录覆盖内置峰谷价格。外部目录不可达时可使用已有缓存；客户端仍可使用内置 DeepSeek 表。外部服务的可用性、数据条款及其更新节奏由相应服务维护。

本仓库不分发外部目录快照、个人会话日志或缓存。

## 安装与状态

参见[仓库安装说明](../../README.md)。包名为 `dsh-plugin-session-meter`。

诊断状态默认写入用户状态目录下的 `dsh-plugins/session-meter`，可通过 `DSH_PLUGIN_STATE_DIR` 或 `SESSION_METER_STATUS_FILE` 覆盖；价格缓存写入临时目录。

## 开发

```sh
node --check lib/index.js
node --check lib/client.js
node --check lib/prices.js
node --test test/*.test.mjs
```

测试使用本地替身，不请求真实价格或汇率接口。

修改客户端或报表源码后，从仓库根目录运行 `node tools/build-client.mjs session-meter` 重新生成客户端和语言文件。
